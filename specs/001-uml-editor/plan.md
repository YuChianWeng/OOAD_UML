---

## Summary

Build a Java 17 + Swing desktop UML editor that supports drawing Rect/Oval basic objects,
three link types (Association, Generalization, Composition), single/multi selection,
move, resize, group/ungroup, and label/fill-color customization. The architecture uses a
Strategy pattern for tool modes, a pure-POJO domain model, and a single-responsibility
Swing view (`CanvasPanel`). All 7 PDF use cases (A–G) must be demonstrable with no
ad-hoc assumptions.

---

## Technical Context

**Language/Version**: Java 17 LTS  
**Primary Dependencies**: Java Swing (JDK standard library only — no third-party libs)  
**Storage**: N/A (persistence out of scope; File menu exists structurally)  
**Testing**: Manual acceptance testing against each User Story; JUnit 5 for unit tests of
  DiagramModel and ToolMode logic (optional, recommended for group/ungroup invariants)  
**Target Platform**: Any desktop OS with JDK 17 (Windows / macOS / Linux)  
**Project Type**: Desktop application (single JAR)  
**Performance Goals**: Repaint ≤ 1 frame (~16 ms) for ≤ 50 objects; no perceptible drag lag  
**Constraints**: Offline, no external network; single JAR compilation; ≤ 100 MB heap  
**Scale/Scope**: Single diagram, ≤ 100 objects/links typical; one window

| VII | Demo-Readiness — end-to-end in < 2 min, no stubs in UI | PASS | Milestone order ensures each use case is fully working before the next begins |
| VIII | Clean Naming — domain vocabulary from spec | PASS | `ClassBox` → `RectObject`, `AssociationLink`, `SelectMode`, `DiagramModel`, `ToolMode` etc. |
| IX | Incremental Milestones — one use case at a time, testable before next | PASS | 6 milestones mapped 1:1 to User Stories P1–P6 |

## Interaction Flows

### Flow 1 — `mousePressed` in `SelectMode`

```
CanvasPanel.mousePressed(e)
  └─► activeToolMode.onMousePressed(e, model, canvas)   [SelectMode]
        │
        ├─ 1. PORT HIT CHECK
        │    For each BasicObject in model (any order — ports are visible only when hovered/selected):
        │      for each port in object.getPorts():
        │        if distanceSq(e.getPoint(), port) ≤ PORT_RADIUS² → RESIZE branch
        │          state = RESIZING
        │          resizeTarget = object
        │          resizePortIndex = portIndex
        │          return
        │
        ├─ 2. OBJECT HIT CHECK (reverse z-order — frontmost first)
        │    for i = model.objects.size()-1 downTo 0:
        │      if model.objects[i].contains(e.getPoint()):
        │        state = MOVING
        │        model.moveToFront(object)        // list.remove + list.add
        │        selection = [object]
        │        moveOffset = e.getPoint() - object.getBoundingBox().origin
        │        canvas.repaint()
        │        return
        │
        └─ 3. EMPTY CANVAS
             state = DRAG_SELECTING
             dragStart = e.getPoint()
             canvas.repaint()
```

### Flow 2 — `mouseDragged` in `SelectMode`

```
SelectMode.onMouseDragged(e, model, canvas)
  ├─ RESIZING:
  │    newBounds = computeResizedBounds(resizeTarget, resizePortIndex, e.getPoint())
  │    // reversed drag: swap corners if needed; clamp min 20×20
  │    resizeTarget.resize(newBounds)
  │    canvas.repaint()
  │
  ├─ MOVING:
  │    newOrigin = e.getPoint() - moveOffset
  │    selection[0].moveTo(newOrigin)
  │    canvas.repaint()
  │
  └─ DRAG_SELECTING:
       dragRect = Rectangle(dragStart, e.getPoint())  // normalized
       canvas.setDragRect(dragRect)
       canvas.repaint()
```

### Flow 3 — `mouseReleased` in `SelectMode`

```
SelectMode.onMouseReleased(e, model, canvas)
  ├─ RESIZING:
  │    finalize — bounding box already updated during drag
  │    state = IDLE
  │
  ├─ MOVING:
  │    finalize — position already updated during drag
  │    state = IDLE
  │
  └─ DRAG_SELECTING:
       enclosed = model.getObjectsCompletelyInside(dragRect)
       if enclosed.isEmpty(): selection.clear()
       else: selection = enclosed
       canvas.clearDragRect()
       state = IDLE
       canvas.repaint()
```

### Flow 4 — Link creation (`AssociationMode` / `GeneralizationMode` / `CompositionMode`)

```
onMousePressed(e, model, canvas):
  source = model.getBasicObjectAt(e.getPoint())   // null if composite or empty
  if source == null: state = INVALID; return
  sourcePortIndex = GeomUtils.nearestPortIndex(source.getPorts(), e.getPoint())
  state = DRAWING
  previewEnd = e.getPoint()

onMouseDragged(e, model, canvas):
  if state == INVALID: return
  previewEnd = e.getPoint()
  canvas.repaint()   // paintComponent draws preview line

onMouseReleased(e, model, canvas):
  if state == INVALID: state = IDLE; return
  target = model.getBasicObjectAt(e.getPoint())
  if target == null || target == source: state = IDLE; canvas.repaint(); return
  targetPortIndex = GeomUtils.nearestPortIndex(target.getPorts(), e.getPoint())
  model.addLink(new Link(linkType, source, sourcePortIndex, target, targetPortIndex))
  state = IDLE
  canvas.repaint()
```

### Flow 5 — Shape creation (`RectMode` / `OvalMode`) — transient

```
onMousePressed(e, model, canvas):
  pressPoint = e.getPoint()

onMouseDragged(e, model, canvas):
  previewBounds = normalizedRect(pressPoint, e.getPoint())
  canvas.setPreviewBounds(previewBounds)
  canvas.repaint()

onMouseReleased(e, model, canvas):
  bounds = normalizedRect(pressPoint, e.getPoint())
  bounds.width  = max(bounds.width,  20)
  bounds.height = max(bounds.height, 20)
  obj = (this instanceof RectMode) ? new RectObject(bounds) : new OvalObject(bounds)
  model.addObject(obj)
  canvas.clearPreviewBounds()
  canvas.setActiveTool(previousMode)   // revert to prior mode (transient behavior)
  canvas.repaint()
```

### Flow 6 — `paintComponent` in `CanvasPanel`

```
CanvasPanel.paintComponent(Graphics g):
  g2 = (Graphics2D) g
  // Draw all GraphicObjects in z-order (index 0 first, last on top)
  for obj in model.getObjects():        // index 0 → last
    obj.draw(g2)
    if obj is hovered (basic) → draw port squares
    if obj is hovered (composite) → draw bounding box outline
    if obj is selected → draw selection indicator

  // Draw all links on top of shapes
  for link in model.getLinks():
    link.draw(g2)   // recomputes endpoints from source/target ports

  // Draw transient overlay (preview shape, drag-select rect, link preview)
  if previewBounds != null: draw preview shape
  if dragRect != null: draw dashed rectangle
  if linkPreview != null: draw preview line from source port to mouse
```

## Milestone Breakdown

### M1 — Application Shell (P1 prerequisite)

**Goal**: Runnable window with correct layout; toolbar button switching works.

**Deliverables**:
- `Main`, `MainFrame`, `ToolBar`, `CanvasPanel` (blank canvas)
- 6 toolbar buttons; pressing any button highlights it, deselects others

**Acceptance**: Window appears; all 6 buttons clickable; one always dark.

---

### M2 — Shape Creation (User Story P1)

**Goal**: Rect and Oval can be drawn on the canvas; z-order list is active.

**Deliverables**:
- `RectObject`, `OvalObject`, `BasicObject`, `GraphicObject`, `DiagramModel`
- `PortUtils` (port computation — needed for rendering later)
- `RectMode`, `OvalMode` (transient behavior; revert to previous mode)
- `CanvasPanel.paintComponent` iterates model list

**Acceptance**: User Story 1 acceptance scenarios 1–3 pass.

---

### M3 — Select, Hover, Move, and Depth (User Story P3 partial)

**Goal**: Click to select; hover shows ports/bbox; drag to move; z-order correct.

**Deliverables**:
- `SelectMode` (IDLE → MOVING branch and EMPTY branch)
- `GeomUtils` (containment helpers)
- `CanvasPanel` hover tracking via `mouseMoved`
- `DiagramModel.moveToFront` (list.remove + list.add)

**Acceptance**: User Story 3 scenarios 1–5 pass; User Story 6 scenarios 1–3 pass.

---

### M4 — Link Creation (User Story P2)

**Goal**: All three link types can be created between basic objects with correct arrowheads.

**Deliverables**:
- `Link`, `LinkType`
- `AssociationMode`, `GeneralizationMode`, `CompositionMode`
- `Link.draw(g2)` with three distinct arrowhead renderers
- `DiagramModel.getBasicObjectAt`, `addLink`, `getLinks`

**Acceptance**: User Story 2 acceptance scenarios 1–6 pass; links redraw when objects move.

---

### M5 — Resize and Multi-Selection (User Story P3 full + P4)

**Goal**: Port-drag resizes basic objects; drag-rectangle selects multiple objects; Group/Ungroup work.

**Deliverables**:
- `SelectMode` RESIZING branch (reversed drag, 20 px clamp)
- `SelectMode` DRAG_SELECTING branch
- `CompositeObject`, `DiagramModel.group`, `DiagramModel.ungroup`
- Edit → Group / Ungroup menu wiring in `MainFrame`

**Acceptance**: User Story 3 scenarios 6–9, User Story 4 scenarios 1–7 pass.

---

### M6 — Label Customization and Final Polish (User Story P5 + P6 verification)

**Goal**: Label name and fill color dialog; all edge cases verified; demo-ready.

**Deliverables**:
- `LabelDialog` (JTextField + JColorChooser; OK/Cancel)
- Edit → Label wiring in `MainFrame` (enabled only when 1 basic object selected)
- Edge case sweeps for all FR edge cases listed in spec
- Remove all debug `System.out.println` statements

**Acceptance**: User Story 5 scenarios 1–5 pass; all 7 PDF use cases demonstrable end-to-end.

## Technical Risks and Mitigations

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| SelectMode priority bugs (port vs body vs empty) | High | High | Implement FR-023's 3-branch logic as explicit state machine; unit-test each branch independently before integrating |
| Reversed-drag resize produces wrong bounding box | Medium | High | Normalize rectangle (always positive w/h) before applying; write unit test with 4 corner directions |
| CompositeObject bounding box stale after child move | Medium | Medium | Compute bounding box on demand (`getBoundingBox()` iterates children each call); never cache |
| Link endpoints not updating after move/resize | Medium | High | Links store object references + port index; endpoints recomputed in `draw()` — no listener needed |
| Z-order broken by list mutation during iteration | Medium | High | Always copy list or iterate a snapshot when mutating; `moveToFront` called outside `paintComponent` |
| Repaint performance degrading on many objects | Low | Medium | All shapes are trivial Swing fills; no bitmaps; 50-object canvas well within Swing's capability |
| Transient mode revert fails when Rect/Oval pressed twice | Low | Medium | Store `previousMode` reference in `CanvasPanel`; update only when a non-transient tool is pressed |
| Group operation leaves stale links pointing to ungrouped children | Low | High | Links reference `BasicObject` instances directly; compositing only moves ownership in DiagramModel list; link references remain valid |
| LabelDialog color chooser blocks EDT | Low | Low | JColorChooser is modal and runs on EDT by default in Swing; standard usage is safe |
| JPanel repaint flicker during drag | Low | Low | Enable double-buffering (default in Swing JPanel); no explicit extra buffering needed |
